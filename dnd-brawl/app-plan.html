Overview

Purpose

A fun rogue-like game Dnd fans can play and attempt to win.

Audience

Dnd fans, chill gamers, new programmers

Dynamic elements

The user will have the option to attack the character/creature or try and recruit them. Once the initial attack begins, the character/creature will also attack the user lowering the users hit points. The user and the character/creature will take turns attacking one another until one of them dies. If the User dies, it's game over and the User has to start again. If the character/creature dies, the next character/creature card comes up and that character/creature's level is one higher than the previous character/creature was and their health is a bit higher as well. The recruit button has a 50% chance at recruiting the character/creature. If failed, the character/creature leaves and the next character/creature arrives NOT leveled up. If successful, the character/creature will go into the User's inventory and that character/creature (Now referred to as an Ally) will assist in attacking if the User attacks a character/creature. After the character/creatures hit level 10 and is defeated, the User has won the game.
